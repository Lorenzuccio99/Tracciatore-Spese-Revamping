TRACCIATORE SPESE REVAMP – v2

Base: revamp completo della versione precedente, con nuova interfaccia Liquid Glass.
Repository GitHub suggerito: Tracciatore-Spese-Revamping

ISTRUZIONI:
1) Estrarre tutti i file dello ZIP.
2) Caricare tutto nella radice del repository GitHub.
3) Attivare GitHub Pages da Settings > Pages > Deploy from a branch > main > /(root).
4) Al primo avvio online installa la modalità offline.
5) Per trasferire i dati della vecchia app, entra in Impostazioni > Importa backup precedente e seleziona il JSON esportato dalla versione precedente.

NOTE IMPORTANTI:
- Questa versione usa una chiave di storage locale separata per non sovrascrivere automaticamente i dati della vecchia app sullo stesso dominio GitHub Pages.
- I backup JSON delle versioni precedenti restano leggibili tramite Importa Backup.
- Non pubblicare mai backup JSON reali su GitHub pubblico: contengono dati personali.
